# IndexCollector Dashboard

Run the dashboard from the project root:

```powershell
.\.venv\Scripts\python.exe dashboard\app.py
```

Then open http://127.0.0.1:5000 in a browser.

The Start button launches `main.py` in the selected mode. Stop ends that collector process only; it does not stop the dashboard server. Press `Ctrl+C` in the PowerShell window to stop the dashboard server.
